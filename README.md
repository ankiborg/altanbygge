# Altanplaneraren

A deck planning and visualization tool. Configure your deck — wall attachment,
dimensions, height, and board direction — and see the result in a 2D top-down
plan and an interactive 3D perspective view.

## Tech stack

| Tool | Purpose |
|------|---------|
| [React](https://react.dev/) | UI component library |
| [Vite](https://vitejs.dev/) | Dev server and build tool |
| [TypeScript](https://www.typescriptlang.org/) | Static type checking |
| [Tailwind CSS](https://tailwindcss.com/) | Utility-first styling |
| [shadcn/ui](https://ui.shadcn.com/) | Accessible UI components |
| [Three.js](https://threejs.org/) | 3D perspective rendering |
| [Zustand](https://zustand-demo.pmnd.rs/) | Lightweight state management |

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
